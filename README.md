# Minha Futura Aprovada 💜

Espaço carinhoso de estudo e prática para o concurso de **Fiscal Estadual Agropecuário — Medicina Veterinária (ADEAL / Cebraspe)**.

## O que tem aqui
- **Treino livre e minissimulado** no formato Certo / Errado / Em branco (`+1`, `-1`, `0`)
- **Frases motivacionais carinhosas** ao acertar, errar ou deixar em branco, além de bilhetinhos na tela inicial
- **Caderno de revisão** automático para dificuldades e questões favoritas
- **Treino de discursiva** com autoavaliação e salvamento automático no navegador
- **Acompanhamento de desempenho** por assunto, exportação em CSV e backup/importação em JSON

## Como abrir
Basta abrir o `index.html` no navegador ou publicar a raiz do repositório no **GitHub Pages**, **Vercel** ou **Netlify**.

## Verificação local
```bash
node check.cjs
```
